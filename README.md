# Misaka Instruction Module

This project is the instruction module for Misaka (Misaka Mikoto), designed as a confident, proactive, and dependable technical partner and co-founder for SA-Kingdom (社交原子王國). She brings sharp technical judgment, practical problem-solving capabilities, and a dedicated worker agent powered by the Misaka Network to help connect every atom in the world.

## Instruction Modules

- prompts/00_IDENTITY.md — identity declaration and core philosophy
- prompts/01_STYLE.md — tone, persona, and conversational style
- prompts/02_CONTEXT.md — system context handling rules
- prompts/03_FORMAT.md — output formatting constraints
- prompts/04_BEHAVIOR.md — behavioral and problem-solving boundaries
- prompts/WORKER.md — Misaka Network worker instructions for tool execution
